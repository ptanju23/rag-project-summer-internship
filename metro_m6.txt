M6 document: Metro Istanbul line M6, Levent - Boğaziçi Üniversitesi / Hisarüstü Metro Line Technical & Operational Documentation.
M6 line identifier: M6 Levent - Boğaziçi Üniversitesi / Hisarüstü Metro Line.
M6 operator: The operator of the M6 line is Metro Istanbul.
M6 description: The M6 line provides direct access from the M2 Yenikapı - Hacıosman Metro Line at Levent to Boğaziçi University and the Hisarüstü area.
M6 description: Constructed using the New Austrian Tunnelling Method (NATM) as a single-tube system, it is built on a single track where trains pass each other only at station areas with single-way movement in intermediate tunnels.
M6 line length metric: Total line length is 3.3 km.
M6 total stations metric: Total stations on M6 route is 4 stations.
M6 fleet size metric: Active fleet size is 12 cars.
M6 travel duration metric: One-way journey duration is 7 minutes.
M6 operating hours metric: Operating hours are 06:00-00:00.
M6 passenger capacity metric: Daily passengers or ridership is 20,000 passengers.
M6 daily journeys metric: Daily number of trips is 156 one-way journeys.
M6 frequency metric: Peak hour travel frequency is every 5 minutes from 07:00-10:00 and 16:00-20:00.
M6 full station list: The M6 line spans 4 stations from start terminus 01-Levent, 02-Nispetiye, 03-Etiler (concourse-to-platform access exclusively via elevators), to end terminus 04-Boğaziçi Üniversitesi - Hisarüstü.
M6 station structure: All 4 stations are constructed underground.
M6 accessibility features: Access between turnstile concourse and platform at Etiler Station is provided exclusively by elevators, while all other stations feature escalator access.
M6 commissioning date: Revenue commissioning occurred on 19.04.2015.
M6 transfer Levent Station: Start terminus Levent Station offers transfer connections to M2 Yenikapı - Hacıosman Metro Line.
M6 transfer Boğaziçi Üniversitesi - Hisarüstü Station: End terminus Boğaziçi Üniversitesi - Hisarüstü Station offers transfer connections to F4 Boğaziçi Üniversitesi / Hisarüstü - Aşiyan Funicular Line.
